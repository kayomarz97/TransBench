# TransBench

## What it is
TransBench is a research assistant that turns a doctor's plain-language bedside observation into a grounded, testable, bench-ready experiment. It breaks the observation into biological mechanisms, writes falsifiable hypotheses, checks each one against real published papers (PubMed + Europe PMC with resolvable PMIDs), throws out textbook facts and unsupported guesses, and — for what survives — hands back one runnable computational experiment naming a concrete public dataset plus a paste-ready prompt for Claude Science. If the evidence isn't there, it ships nothing rather than hallucinate.

Technically it is an 8-agent LangGraph engine (three-tier Claude: Opus for hypothesize/experiment-design, Sonnet for decompose/novelty, Haiku for grade/entail/assemble) with three "rigor gates", packaged as an MCP connector (FastMCP, `mcp==1.28.1`) for Claude Science. It was built for the "Built with Claude: Life Sciences" hackathon (Anthropic × Gladstone Institutes × Cerebral Valley).

## What it entails
- `src/transbench/` — the engine: `engine.py` (`run_transbench` entrypoint), `graph.py` (LangGraph wiring), `agents.py`, `rigor.py` (rigor gates), `search_sources.py` (PubMed/Europe PMC/GEO retrieval), `schemas.py` (TransBrief), `prompts.py`, `config.py`, `reuse.py`.
- `src/vendored/` — a **read-only mirror of the Iatronix backend** (`app/`, `config/providers.yaml`, `data/medical_journals.json`); the default self-contained backend.
- `mcp_server/` — `server.py` (FastMCP, exposes `generate_experiment`, `search_grounded_evidence`, `get_experiment_result`), `manifest.json`, `run_stdio.sh` / `run_http.sh`, `ask.py`.
- `snapshots/`, `golden-test-results/` — real captured runs (incl. the flagship PTPN2-in-Tregs experiment on Gladstone's GSE278572) used as byte-reproducible README evidence.
- `demo/`, `build/`, `output/`, `assets/` — assets for the 3-minute demo film (bulk of the ~503 MB).
- Docs: `README.md`, `BUILD_SPEC.md`, `PLAN.md`, `INSTALL_AGENT.md`, `CLAUDE_SCIENCE_SETUP.md`.
- Stack: Python ≥3.11, LangGraph/LangChain + `langchain-anthropic`, MCP/FastMCP, `httpx[socks]`, pydantic v2, FastAPI, tenacity. Managed with `uv`.

## How it works
Claude Science (the MCP client) spawns the server over stdio (HTTP/SSE fallback on `127.0.0.1:8500`). `generate_experiment(observation)` is async submit+poll: returns a `job_id` in <1s (a run legitimately takes ~60–120s, ~13–16 LLM calls), and `get_experiment_result(job_id)` is polled until `done`. Inside, the LangGraph engine decomposes the observation into biological axes, generates ≤3 hypotheses, grounds each against live multi-database retrieval (PubMed + ClinicalTrials.gov + Europe PMC), applies novelty/entailment rigor gates (established / open_question / unsupported), content-verifies a proposed public dataset (GEO, Tabula Sapiens) via a live fetch, and emits a TransBrief with one experiment and a `claude_science_prompt`. `reuse.py` is the single seam to the Iatronix backend: a `try/except ImportError` — Path B (bundled `src/vendored/` mirror) is the default; Path A (`REUSE_SOURCE=installed_iatronix`) is an opt-in editable install of the live backend.

## Change impact / blast radius
- **Upstream (this depends on):** Anthropic API (BYOK), NCBI/PubMed, Europe PMC, ClinicalTrials.gov, GEO; LangGraph/LangChain, MCP/FastMCP SDK; the Iatronix backend logic — vendored in by default, or the live [[med-ai-project]] backend via Path A.
- **Downstream (depends on this):** Claude Science (the MCP client consuming the connector); [[TransBench-demo]] (the demo film built from these runs).
- **Parallel / shared (can break if touched):** `src/vendored/` mirrors [[med-ai-project]]'s Iatronix source (`app.services.*`, `providers.yaml`, `medical_journals.json`) — if the upstream contract changes, only `reuse.py` should need updating, but the vendored copy silently drifts from the real backend.
- **⚠️ Danger zones (touch with care):**
  - `.env` **contains a live `ANTHROPIC_API_KEY` and a `PUBMED_API_KEY`**. It is correctly gitignored, so not committed — but the plaintext secrets exist on disk; do not print, copy, or publish this file.
  - `reuse.py` — the one seam to Iatronix; a wrong import breaks both backends. Only DB-free leaf functions may be imported (never `run_search_graph`/`semantic_cache`/`vector_search`).
  - `mcp_server/server.py` tool signatures are the live authoritative schemas (`manifest.json` is descriptive only) — changing them changes the connector contract Claude Science relies on.
  - README/snapshots reproducibility guarantee: figures are regenerated byte-identically from committed `snapshots/`; editing snapshots breaks the "nothing is mocked" claim.
